# Reusable Prompts

## Paper section explainer

```text
Explain this paper section for a generative modelling course project.
Separate source-backed facts from interpretation.
Preserve equations and define symbols.
End with 3 presentation-ready bullets and 3 open questions.
```

## Code inspection

```text
Inspect this code path for the Z-Sampling project.
Identify the algorithm entry points, important parameters, expected inputs/outputs, and reproduction risks.
Do not rewrite code unless asked.
```

## Experiment planner

```text
Design a small, reproducible experiment for comparing standard diffusion sampling against Z-Sampling.
Include hardware assumptions, commands, seeds, outputs, metrics, and failure modes.
```
