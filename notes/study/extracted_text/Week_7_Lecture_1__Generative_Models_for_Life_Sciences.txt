Conditioning vs guidance
Often used interchangeably in literature; both model conditional 𝑝 𝐱 𝐲 ; differences:



  Conditioning                                  Guidance

  Changes in the target distribution            Changes in the sampling trajectory
             𝑝 𝐱 → 𝑝 𝐱 𝐲                                 𝐱 𝑡 ← 𝐱 𝑡 + 𝛼∇𝐱 𝑓 𝐱 𝑡

  The condition is part of the model input      An external objective steer generation

  What should be generated given context?          Where should the sample move to?

Why motifs matter
▪ In many protein design cases, we are not interested in modifying the motif to
  maintain the protein function

▪ In turn, we want to optimize the scaffold to get a protein with better properties
  (e.g., more stable)

▪ Conditional generation problem → given a functional motif, generate a protein
  scaffold that supports it
                                𝑝 𝐱 = scaffold | 𝐲 = motif


▪ Example of motif: enzyme active sites

Latent diffusion for protein sequences
▪ Structural data is complex (geometry, preserve equivariance) and highly scarce
      → protein sequence data is abundant and easier to manage

▪ Discrete diffusion requires sampling from a Multinomial distribution

▪ Can we use continuous representations for protein sequence design?
     → DiMA: diffusion on protein language model embeddings (e.g., ESM-2)

▪ Conditional generation problem → generate protein sequence embeddings
