Evaluation paradigm
• Usually we have train set and test set
• After training on the train set, we apply the model to test set
   • Density evaluation
      • Are the models assigning test data high probability?
   • Sample evaluation
      • Are samples generated from the model good enough? (Or are they “close” enough to the
        distribution of test set data?)
   • Downstream tasks
      • Is the model supporting desired application well?


• Evaluating GMs is multi-objective

Good sample doesn’t imply high likelihood

Frechet Inception Distance (FID)
• FID measures similarities in the feature representations, instead of class
  labels
   • Still requires the feature extractor
• Define sample set 𝑆𝑆 and test set 𝑇𝑇
   • Get feature representations 𝐹𝐹𝑆𝑆 and 𝐹𝐹𝑇𝑇 respectively
• Fit two multivariate Gaussian models of each of them
   • Mean: 𝜇𝜇𝑆𝑆 and 𝜇𝜇 𝑇𝑇 ; covariance: 𝛴𝛴𝑆𝑆 and 𝛴𝛴𝑇𝑇


   • Low FID is better

  Precision & recall
  • Reference distribution P, model distribution Q
  • Precision: how much generated data (Q) lies near the real data
    manifold (P)
  • Recall: how much of the real data manifold (P) is covered by the
    generator (Q)

Drawbacks of pretrained classifiers
• Most metrics introduced so far require pretrained classifiers
• However, one might not have the classifier trained on identical
  dataset used for generation
• Classifier might not be reliable enough

Downstream tasks concerns
• What is the model intended for?
   • Image editing/denoising: reconstruction quality;
   • Text generation: human preference/truthfulness;
   • Data augmentation: training quality after augmentation

• A model is good only when it performs well on the application that
  it’s intended to support.

Summary
• Quantitative evaluation of generative models is challenging
• Metrics can significantly vary based on end goal: density estimation,
  sampling, latent representations
   • Know their advantages and drawbacks
• Evaluation should support downstream tasks / end goals, if there are

• There is no universal best metric. Evaluate the distributional
  property you care about.
