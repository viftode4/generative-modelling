# Course Document Extracts

This folder contains machine-readable text extracts from the official course PDFs. Keep the PDFs in `docs/course/` as the source of truth.

Files:

- `project-description-brightspace.txt` - extracted from `docs/course/project-description-brightspace.pdf`.
- `project-rubric.txt` - extracted from `docs/course/project-rubric.pdf`.
- `requirements-summary.md` - distilled project requirements and repo implications.

If a PDF changes, replace the PDF, regenerate the corresponding `.txt`, then update `requirements-summary.md`.
