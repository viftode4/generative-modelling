# docs

## Purpose

External documentation **in original binary form** — primarily the official course PDFs. Text-extracted, searchable versions live in `knowledgebase/course/`; this folder is the unmodified provenance copy.

## Subdirectories

| Directory | Purpose |
|-----------|---------|
| `course/` | Official course PDFs (project description, rubric) plus a small README pointing at the extracted text. |

## For AI Agents

### Working In This Directory

- **Do not modify the PDFs.** They are the as-issued versions and must remain identical to what was downloaded.
- When new course PDFs arrive, **also** drop a text extraction into `knowledgebase/course/` so it stays grep-able. Document the extraction in `knowledgebase/research-log.md` with the date and source URL.
- This folder is **not** for project-internal documentation — that lives in `knowledgebase/` or `AGENTS.md` files. Reserve `docs/` for *external* artifacts the course or third parties handed us.

## Dependencies

### Internal
- `knowledgebase/course/` — searchable text mirror of these PDFs.
